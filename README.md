# 🌙 Roza Siyam

**Advanced Ramadan Timings Tracker & Fasting Companion**

![Version](https://img.shields.io/badge/version-1.0-amber)
![Status](https://img.shields.io/badge/status-inactive-red)
![PWA](https://img.shields.io/badge/PWA-Optimized-blue)

**Roza Siyam** is a mobile-first Progressive Web Application (PWA) designed for tracking fasting schedules. It features real-time countdowns, localized city timings, and dynamic Fiqa adjustments.

⚠️ **Note:** This project is **Currently Inactive**. It is maintained seasonally and will be updated for the next Ramadan cycle.

🔗 **Live Demo:** [https://gem-labs-pk.github.io/roza-siyam/](https://gem-labs-pk.github.io/roza-siyam/)

---

## 🚀 Key Features

* **Smart Dashboard:** Real-time countdowns to Sehr and Iftar based on current fasting state.
* **Localized Timings:** Searchable city selector mapped to exact coordinates.
* **Fiqa Engine:** Support for both Hanafi and Jafiria schools of thought with automatic time offsets.
* **Native Experience:** PWA-ready with bottom tab navigation, glassmorphism UI, and offline caching.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Vanilla JavaScript (ES6+), Tailwind CSS
* **PWA:** Web Manifest & Service Workers
* **Data:** Integrated Aladhan API methodology for precise calculations.
